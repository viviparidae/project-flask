# Project: FLASK — ビジョン・スコープ定義書 (Vision and Scope Document)

- **文書バージョン**: 1.1.0
- **策定日**: 2026-10-06
- **ステータス**: Approved
- **対象**: React / Vite / TypeScript スタンドアロンフロントエンド
- **準拠規格**: 『ソフトウェア要求 第4版』 / ISO/IEC 29148

## 1. ビジネス要求

Project: FLASK は、異世界薬局、ブレイキング・バッド、VA-11 Hall-A の要素を生かした会話×化学合成アドベンチャーゲームである。プレイヤーは、患者との対話、原子の生成、反応条件の制御、純度による因果判定を、フロントエンドだけで行う。

## 2. スコープ

### 2.1 対象

- React/Vite/TypeScriptによるフロントエンド画面
- 対話診断と推奨ターゲットの表示
- 設備Tier、温度、触媒滴数による純度計算
- 反応結果の決定論的な表示
- 静的資産としての実行

### 2.2 対象外

- Python / Flask バックエンド
- 外部API、DB、認証、データ永続化
- リアルタイム3Dグラフィックス
- マルチプレイヤー

## 3. 技術制約

- TypeScript 5.7 以上、React 18、Vite 6
- Node.js 20 以上
- npm package manager
- Vitest、Testing Library、jsdom
- 外部サービスを使用しない
- フロントエンドのビルドとテストだけで起動可能

## 4. 要求の追跡

- REQ-CHEM-01〜04: 純度計算
- REQ-TALK-01: 対話診断
- NFR-PERF-01: 応答性能
- NFR-REPR-01: 決定論性

## 5. 次のステップ

1. React UIを実装する。
2. 純度計算を純粋関数として実装する。
3. UIと計算の受け入れテストを実行する。
4. Vite本番ビルドとESLintを実行する。
