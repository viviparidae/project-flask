# [ADR-0003] React / Vite / TypeScript スタンドアロンフロントエンドの採用

* **ステータス**: Accepted
* **決定者**: Project: FLASK 開発チーム
* **日付**: 2026-10-06
* **関連要求**: `REQ-CHEM-*`, `REQ-TALK-*`, `NFR-REPR-01`, `NFR-PERF-01`

## 1. 文脈と問題提起

既存のPython/Flask構成では、フロントエンドが暗黙的にサーバーまたはPythonプロセスに依存し、単独で実行・検証できない。今回の要件では、React、Vite、TypeScriptを用いたスタンドアロンなWebアプリを直接提供することが必要である。

## 2. 検討した選択肢

- **選択肢 A: Python/Flaskされたバックエンドを前提とする**: 既存構成を維持するが、フロントエンドの単独性と再現性を失う。
- **選択肢 B: React/Vite/TypeScriptのスタンドアロンフロントエンド**:ブラウザ内で完結し、Viteの開発・ビルド・テストを単独実行できる。

## 3. 決定と根拠

選択肢 Bを採用する。ReactによるUI、TypeScriptによる型安全性、Viteによる高速な開発と静的ビルド、Vitestによる実コンポーネントテストを組み合わせる。Pythonのバックエンド依存は新規アプリから除外する。

## 4. 結果

- フロントエンドは静的資産として配布できる。
- APIや外部サービスへの依存を持たない。
- 純度計算は純粋なTypeScript関数として実装する。
- UIと純度計算を実コンポーネントテストで検証する。
- 既存のPythonテストは新しいTypeScriptテストへ置き換える。
