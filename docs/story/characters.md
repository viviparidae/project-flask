## 主人公（Player Character）

```
職業  : 旅の化学者
通称  : 「荒野の化学者」（評判 75 以上で定着）
拠点  : 荒野の仮設テント（移動式実験室）
特技  : 観察・分析・調合・毒性判定
弱点  : 人付き合いが下手。「魔法使い」と呼ばれると反応する
```

### 口調のサンプル（選択肢に反映）

| 状況 | 口調の例 |
|------|---------|
| 丁寧に接する | 「お役に立てるか分かりませんが、分析してみましょう。」 |
| 鋭く観察する | 「……その傷の角度、普通の摩耗じゃない。何があった？」 |
| 突き放す | 「化学は万能じゃない。期待しすぎないように。」 |
| 金にシビア | 「依頼なら先に金を。感謝は受け取れないもので。」 |

### 信念（ゲームを通じて揺らぐもの）

1. 「化学には嘘がない。結果だけが真実だ。」
2. 「知識を持つ者は、その使い方に責任を持つ。」
3. 「依頼人の事情には踏み込まない。俺は化学者だ、相談者じゃない。」

> ③の信念は、物語が進むにつれて崩れていく予定。

## エピソード1 登場人物

### ガルド（Gard）

```
年齢  : 40代後半
職業  : 鍛冶師（鍛冶師組合所属）
外見  : 巨躯。傷だらけの手。無精髭。革エプロン
口調  : 短く、ぶっきらぼう。しかし正直
一人称: 俺
```

**依頼の背景:**

父親 — 若い頃、沿岸の港町「シルトハーフェン」の鍛冶場で働いていた職人。  
数十年にわたって海沿いの鍛冶場で腕を磨いたが、老いて内陸に戻り死去。  
遺品の荷物から長剣が出てきた。父が作ったものか、誰かから受け取ったものかは不明。  
黒錆と塩化物錆の複合腐食で刃全体が覆われており、鍛冶師仲間では手の出せない状態。

**セリフ集:**

```
「……頼む。これを見てくれ。」（剣を差し出す）

「うちの親父が死ぬ前に残した剣だ。何とかしてやりたい。」

「完璧じゃないが……これだけ戻れば上等だ。助かった。」（GOOD 結果）

「……親父の顔が、刃に映っている。ありがとう。」（PERFECT 結果）

「何をしてくれた……！ これじゃ使い物にならない！」（DAMAGED 結果）

「こんな化学者に頼んだ俺が馬鹿だった……」（事故結果）
```

**評判が上がると（PERFECT 結果後）:**  
鍛冶師組合に「荒野の化学者」として紹介し、今後の依頼ルートが開ける。

## エピソード2 以降（企画中）

### ナーラ（Ep.2 染料職人）

```
年齢  : 20代前半
職業  : 染色職人（見習い）
外見  : 染料で色づいた指先と袖。いつも焦っている
口調  : 早口で感情的。焦りと恥ずかしさが混在
```

**依頼の背景:**

主人公を「なんとかしてくれる人」として半泣きで訪ねてくる。

### オルベン（Ep.3 村長）

```
年齢  : 60代
職業  : 村長（小集落の自治責任者）
外見  : 白髪の痩せた老人。杖をつく
口調  : 丁寧だが疑り深い。化学を信用していない
依頼  : 村の井戸水の汚染調査と対処
```

**依頼の背景:**  
鉛管の腐食による水質汚染。家畜が次々と弱り始めた。  
村人への周知を避けたいと考えているが、その判断が誰かを傷つける可能性がある。
