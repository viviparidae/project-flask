## 1. 世界観

### 舞台

文明と荒野が混在する**疑似近世ヨーロッパ風の異世界**。  
錬金術と化学が境界線上に存在し、人々は「魔法使い」と「化学者」を混同する。  
主人公はその誤解を利用することも、否定することもある。

- 都市には薬師ギルド・鍛冶師組合・商人組合が存在する
- 荒野には定住しない「旅の技術者」がテントを張って生計を立てる
- 化学的知識は希少であり、正しく使えば絶大な信頼を得られる

### コンセプト

> **「化学者として、世界の問題を解け。」**

魔法が当たり前の世界で、主人公は**化学（実験・反応・分析）** によって問題を解決する旅人。  
序盤は生活上のトラブル（腐食・汚れ・材料の不足）を化学で解決し、  
物語が進むにつれて、危険な依頼・政治的陰謀・医療的問題が絡み合っていく。

### ゲームの精神

| 要素 | 参考作品 | 本作での解釈 |
|------|---------|------------|
| 依頼人との対話・信頼構築 | VA-11 Hall-A | バーテンダーではなく、旅の化学者としての問診 |
| 道徳的選択と因果応報 | 異世界薬局 | 処置の精度が依頼人の運命を変える |
| 知識と倫理の危うさ | ブレイキング・バッド | 化学は使い方次第で薬にも毒にもなる |

## 2. 主人公（プレイヤーキャラクター）

### 基本設定

| 項目 | 設定 |
|------|------|
| 職業 | **旅の化学者** |
| 通称 | 「荒野の化学者」（評判が上がると定着する二つ名） |
| 性別 | 設定なし（プレイヤーの想像に委ねる） |
| 外見 | 旅装束。腰に試薬瓶と計量器具。煤で汚れたエプロン |
| 拠点 | 荒野に張った仮設テント（移動式の化学実験室） |

### 性格の軸

- 冷静な観察眼と論理的な思考を持つ
- 感情を排して問題を分析しようとするが、依頼人の事情に引き込まれることもある
- 化学の力を信じているが、その誤用については敏感に反応する
- 「魔法使いと間違えられること」に軽い苛立ちを感じる

### スキルと道具

| カテゴリ | 詳細 |
|---------|------|
| **分析** | 腐食の種類を目視と反応テストで特定する |
| **調合** | 酸・溶媒・触媒を組み合わせて処置液を作る |
| **知識** | 金属化学・有機化学・毒性学の基礎知識を持つ |
| **携行品** | 試薬瓶セット・pH試験紙・小型加熱器・計量スポイト |

### ステータス

| ステータス | 説明 | 初期値 |
|-----------|------|-------|
| **評判** | 依頼人・組合・街での信頼度。0〜100 | 50 |
| **所持金** | 報酬の蓄積。依頼成功で増加 | 80G |

## 3. 登場キャラクター

### エピソード1 登場人物

#### ガルド（Gard）— 鍛冶師

| 項目 | 設定 |
|------|------|
| 年齢 | 40代後半 |
| 外見 | がっしりした体格。傷だらけの両手。日に焼けた顔 |
| 職業 | 鍛冶師。近くの街の鍛冶師組合に所属 |
| 性格 | 口数は少なく不器用だが、誠実で感情が深い |
| 一人称 | 「俺」 |
| 依頼 | 亡き父が遺した古剣の腐食除去 |
| 動機 | 父への想いと敬意。財産的な価値は求めていない |

**背景:**  
父親は若い頃、沿岸の港町の鍛冶場で働いていた。  
死後、遺品の中から黒ずんだ長剣が出てきた。  
何十年も塩の潮風にさらされた**黒錆＋塩化物錆の複合腐食**が、刃全体を覆っている。  
地元の鍛冶師では手が出せず、旅の化学者の噂を聞いてテントを訪ねた。

**関係性の変化:**

| 処置結果 | ガルドの反応 | 関係への影響 |
|---------|------------|------------|
| 完全修復 | 言葉を失い、目に光るものが見える | 鍛冶師組合へ紹介 / 評判+35 |
| 良好な修復 | 渋い顔から安堵の笑みへ | 口コミを広める / 評判+18 |
| 修復不完全 | 複雑な表情。再依頼を示唆 | 評判変動ほぼなし |
| 金属侵食 | 激怒。立ち去る | 組合から警告 / 評判-30 |
| ガス事故 | 咳き込みながら飛び退く | 安全管理失態として周知 / 評判-40 |

## 4. エピソード一覧

### エピソード構造の方針

- **序盤エピソード（Ep.1〜3）**: 病気・医療とは無関係の化学問題
- **中盤エピソード（Ep.4〜7）**: 依頼が複雑化。倫理的判断が増える
- **終盤エピソード（Ep.8〜）**: 医療・薬の調合が本格登場。暗い依頼も

### Ep.5〜7「薬の話が始まる」 💡 構想

物語の中盤で初めて医療・薬の問題が登場する。

**Ep.5「熱病の集落」**  
荒野の小集落で熱病が流行している。  
主人公は薬師ではないが、アスピリン様の化合物（サリチル酸誘導体）を合成する知識を持つ。  
「薬を作る化学者」として初めて医療に踏み込む分岐点。

> ここで初めて `purityEngine.ts` が本格稼働する。

**Ep.6「薬師ギルドからの警告」**  
主人公が薬品を提供したことで、薬師ギルドから「無許可処方」として警告を受ける。  
化学者としての立場と医療倫理の衝突が描かれる。

**Ep.7「毒か薬か」**  
謎の依頼人から「ある化合物」の合成を求められる。  
その化合物は薬にも毒にもなる。依頼人の目的を見極めなければならない。

## 5. 世界観の化学ルール

プレイヤーが直感的に理解できるよう、化学概念を世界観に落とし込んだ表現を使う。

| 化学的概念 | ゲーム内の表現 |
|-----------|-------------|
| pH（酸性/塩基性） | 「液の性質」「辛さ（酸）と灰汁（塩基）の強さ」 |
| 酸化還元 | 「錆は金属が空気に食われた跡」 |
| 触媒 | 「反応を促す媒介物。消費されないが必要」 |
| 副産物 | 「余計なものが生まれる。無害とは限らない」 |
| 濃度 | 「濃いほど強力だが、扱いが難しい」 |
| 温度依存性 | 「熱は反応を速める。しかし暴走もさせる」 |

## 6. 評判システム

依頼の成否が「評判」として蓄積される。評判は新たな依頼へのアクセスを左右する。

```
評判 0〜20   : 「得体の知れない流れ者」。依頼が来にくい
評判 20〜50  : 「腕のいい修理屋」として認知される（初期状態）
評判 50〜75  : 「荒野の化学者」として組合の紹介案件が来る
評判 75〜100 : 「賢者に近い技術者」。難しい・機密性の高い依頼が舞い込む
```

評判が下がりすぎると「危険人物」として街への立ち入りが制限される（Ep.6以降）。
